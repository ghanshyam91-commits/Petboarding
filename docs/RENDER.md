# Render testing deployment

Create a Render Blueprint from this repository's main branch using `render.yaml`.
It declares a free Python web service and a free PostgreSQL 16 database in
Singapore. Review the dashboard estimate before applying: both must be free.
The secret key is generated by Render; the database URL is connected internally.
The database rejects public inbound connections.

The build installs dependencies and collects compressed static files. Startup
runs migrations before Gunicorn; failed migrations stop the deployment. One
worker and two threads limit memory use on the free web instance. `/healthz/`
checks the database without returning connection details. DEBUG stays disabled.

The Render hostname is automatically accepted for Host and CSRF validation.
Add any custom domain explicitly to ALLOWED_HOSTS and CSRF_TRUSTED_ORIGINS.
Forwarded HTTPS headers are trusted only when the Render environment is enabled.

## Limits and initial access

- Free web services sleep after 15 minutes without traffic.
- Render's free PostgreSQL expires after 30 days. Upgrade it or migrate the data
  to a durable PostgreSQL service before expiry. No free database backups are
  included. This Blueprint is for testing, not live boarding operations.
- Upload storage/scanning is not implemented. Do not store pet documents or care
  uploads on the ephemeral web filesystem.
- There is no free background worker or cron service in this Blueprint. Care
  escalation scheduling and external alert delivery remain launch blockers.
- This app has invitation-based accounts. The initial deployment has no default
  admin or demo password. Provision an administrator securely before testing
  authenticated workflows. Free Render instances do not provide a web shell;
  account provisioning needs an explicit one-off deployment command using
  private environment variables or a controlled database connection.
- The local-only demo seeder remains disabled when DEBUG is false.

See IMPLEMENTATION_STATUS.md for the remaining product launch gates. A successful
Render health check does not certify the marketplace as production-ready.
